# ABI-age-structure-MED-NEA-US
Data and R code associated with the Beyond biomass: ABIref evaluating the age-structure of exploited fish stocks across regions

**Beyond biomass: ABIref evaluating the age-structure of exploited fish stocks across regions**

## Contents

- `Data/`: datasets used in the analyses
- `Code/`: R scripts used for indicator calculation, figures, tables and recruitment diagnostics

## Authors

Andrea Pierucci, Jason Cope, Massimiliano Cardinale, Danai Mantopoulou Palouka, Alessandro Orio, Valerio Bartolino, Laurence Kell, Christopher Griffiths

The analyses were performed in R. Package requirements and session information are reported in the scripts.
